# Письмо для Маши 💌

Креативная открытка-сайт с Днём Рождения: конверт с сургучной печатью открывается в письмо, вокруг летят звёзды и тёплые искры, а в конце — тёплые слова от Лео.

## Как открыть

Просто откройте `index.html` в браузере — сайт полностью статичный, без сборки и сервера.

Для проверки на телефоне можно:

1. Запустить локальный сервер в этой папке:
   ```bash
   python -m http.server 8080
   ```
2. Открыть на компьютере `http://localhost:8080`.
3. На телефоне — `http://<IP-компьютера>:8080` (если устройства в одной Wi-Fi сети).

## Что внутри

- `index.html` — разметка и весь текст письма.
- `style.css` — закатная палитра, конверт, бумага, адаптив, анимации.
- `script.js` — открытие конверта, звёзды, прогресс чтения, появление блоков.

## Что можно быстро поменять

- Текст письма — в `index.html` внутри `.letter-body`, финальные строки — в `.closing-note`.
- Имя и подпись — там же, в `.letter-name` и `.signature`.
- Цвета — CSS-переменные в начале `style.css` (`--coral`, `--gold`, `--berry` и другие).

## Публикация

Папку можно загрузить как есть на GitHub Pages, Netlify, Vercel или любой хостинг статики. Главное — сохранить три файла рядом друг с другом.

> Шрифты подключены с Google Fonts. Без интернета сайт останется рабочим, но покажет системные запасные шрифты.
